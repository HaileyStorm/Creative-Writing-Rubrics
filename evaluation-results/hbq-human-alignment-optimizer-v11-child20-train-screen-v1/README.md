# Child20 eight-cell train screen

This is an opt-in, provider-free-by-default development screen over four fixed
TRAIN items and paired baseline/child20 payloads. Prepare before any execution:

```powershell
python evaluation-results/hbq-human-alignment-optimizer-v11-child20-train-screen-v1/study.py --inspect --split-manifest <path> --hanna-csv <path> --successor-contract <path>
```

It has no confirmation, selection, promotion, runtime, generalization, or
Linux authority. A strictly improved Grok mean MAE can open only a later,
separately gated matched Sol-8 measurement; this package does not launch
that measurement.

`report(...)` is provider-free and derives the Grok-only eight-cell TRAIN
projection from admitted persisted receipts; incomplete, duplicate, or
ambiguous receipt evidence raises instead of emitting an aggregate. Its strict
mean-MAE comparison is a later matched Sol-8 gate only, never promotion.
