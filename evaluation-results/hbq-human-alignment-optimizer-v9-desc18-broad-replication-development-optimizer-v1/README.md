# Desc18 Fresh96 open replication optimizer

This provider-free analyzer first requires the pinned reconciliation successor to replay its collector against the immutable failed execution and freeze roots. The reconciliation validates all 64 persisted native receipts without resending them; only that distinct reconciliation study, kind, and source lineage can feed the Fresh96 projection.

It uses Optuna's frozen six-setting `GridSampler` and DSPy examples only to record development evidence. It makes zero model, LM, or `Predict` calls. Child20 can reach a Sol veto only by strictly improving raw MAE and being no worse under every frozen setting; Sol cannot select a substitute.

The analyzer is bound to the reviewed reconciliation package, contract, README, and regression test at commit `b33c501c4d6b87a90d6a5d307f7e025839e4afec`.

python evaluation-results/hbq-human-alignment-optimizer-v9-desc18-broad-replication-development-optimizer-v1/analyzer.py --output-root C:\path\to\desc18-execution --freeze-root C:\path\to\desc18-freeze --collector-path C:\path\to\collector.json
