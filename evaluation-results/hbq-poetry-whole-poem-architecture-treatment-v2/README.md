# Whole-poem architecture wording treatment v2

This provider-free development package freezes a direct-only candidate wording
treatment for `scope.poetry_poem.form`. It is not a registry edit, compiled
module, ordinary bundle claim, execution package, or promotion decision.

The preceding 36-call result and v1 treatment are retained as immutable
negative-discrimination provenance. The v1 candidate still allowed a mere
ending, contrast, or progression to stand in for the structural relationship
this leaf must own. This successor therefore makes the inter-part relationship
and its evidence requirement explicit; it retains no promotion claim.

Five fresh public-synthetic discriminatory carriers test a genuine inter-part
relation, permutation neutrality, an ending-only coda, semantic progression
without an inter-part relation, and incomplete coverage. Two stable public-
synthetic scope controls—a complete single-part poem and an excerpt—are
explicitly inherited from v1; they are not discriminatory oracle cases.
Future contact requires a separately reviewed execution successor; this package
has no transport or execution mode.
