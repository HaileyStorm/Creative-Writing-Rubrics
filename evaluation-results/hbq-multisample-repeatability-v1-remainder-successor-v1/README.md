# Multisample remainder successor

This package preserves the quota-stopped successor root as immutable lineage. It creates a fresh, outcome-blind plan for the 153 genuinely unfinished cells, sequences 178--330. Sequence 178 is intentionally scheduled again from scratch: its two accepted batches and three quota rejections remain evidence only and are never resumed or incorporated.

`run_remainder.py` makes no provider calls. Preparation accepts only a truly empty, external root. A separately reviewed executor must first be sealed as `executor-binding.json`; the binding commits its launcher, the current package, both predecessor layers, all five native-arm prompt/schema pairs, HBQ runner/runtime files, registry, bundles, prompts, and validation schemas. Authorization and launch both reconstruct that binding from its recorded root and launcher, requiring the same clean pushed 33-file projection. `--authorize` then transitively binds the artifact SHA and an externally collected current quota observation from after 2026-08-28T01:21:00Z into a ten-minute, non-executable handoff. A local JSON file is not proof that quota is available: the bound executor must independently revalidate quota at launch, and launch-handoff expiry is enforced. It must create fresh sessions and outputs, prove they are disjoint from both prior lineages, and bind every completion to the new journal.
