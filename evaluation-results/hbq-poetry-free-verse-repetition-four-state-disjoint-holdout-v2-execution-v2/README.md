# S1 fresh-carrier execution successor

This provider-free successor preserves the v2 candidate wording and four-state
geometry while using twelve new opaque samples. The prior execution is retained
only as a one-contact `NO_RESULT_PROMPT_BYTE_BINDING_FAILURE`; it supplies no
vote, carrier, slot, or reusable logical sample here.

Validation and dry freezing use the production runner's in-memory prompt string
and persist its UTF-8 bytes without text-mode newline translation. There is no
claim or live execution entrypoint in this package.
