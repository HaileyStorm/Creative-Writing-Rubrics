# QPC24 v5 aggregate-only terminal projection

This public projection records a terminal local post-output laptop-sleep
timeout. It is not a provider, model, or rubric failure. The final contacted
response was complete and structured, but became nonvoting because the local
controller timed out after laptop sleep before its required receipt and
settings completion step.

The 150-call study planned 3,315 verdict positions. Thirteen calls were
contacted: 12 accepted voting calls cover 269 positions, and one complete
structured but nonvoting call covers 24 positions. The remaining 137 calls and
3,022 positions are untouched. This package reports no discrimination or
model-quality result.

Only an opaque SHA-256 commitment to the private receipt tree is published.
No identifiers, content, quotations, locations, sessions, or per-leaf verdict
states are included here. The private receipt tree remains the reconstruction
authority.
