# HANNA human-alignment study v3

This successor keeps v2's public-data-only, prompt-disjoint protocol: 88 development items, 11 five-run repeatability items, and 88 confirmatory items. It uses only the already-published HANNA ratings; it never requests or creates new human judgements.

Inputs and run outputs live outside this repository. The frozen external work contract records exact source hashes, this contract hash, and exact runtime fingerprints. The analyzer emits prose-free results only after it verifies manifest-v3 and checkpoint-v4 provenance, deterministic score reconstruction, cumulative retry feedback, recovery records, provider artifacts, and session separation.
