# Flash-Next execution contract v1

This provider-free successor freezes one public-synthetic generation cell and one public-synthetic judging cell, including their context, prompt, response schema, sampler, outbound payload, and fixture-only response envelope.  Its local subprocess is a deterministic fixture, not a Linux, Flash-Next, provider, endpoint, or model execution.

Each prepared root is immutable: it records exact payload bytes and a launch intent before the fixture process. A process launch is terminal; there is no fallback or resend. Native execution, pairing, promotion, and native endpoint contact cardinality remain **NO-GO**.

The exact future Linux invocation shape and prerequisites are frozen in `study-contract.json`. The current `native-run` CLI command deliberately refuses execution.
