# HBQ figurative domain-compatibility v1

This provider-free freeze tests a deliberately narrow next figurative repair
family.  It changes no rubric text, ID, owner, leaf, split, or weight.

The target is `penalty.purple_prose.metaphor`: whether the material metaphors
and images applied to their target cohere rather than compete.  Its two
controls remain deliberately separate: `no_default_metaphors` owns stockness,
and `purple_prose.proportion` owns density/material load.

Eight public synthetic artifacts form an orthogonal 2 x 2 x 2 grid:
cooperating/competing source domains, default/specific stockness, and
routine/charged material load.  Each has exactly two material figures.  Both
arms use the frozen P1 applicability-and-evidence appendix; the treatment arm
adds only the exact leaf-specific aid.  Three singleton repetitions for three
leaves across both arms make 144 prospective zero-paid calls.

Expected verdicts are local ledger fields only and never enter a provider
prompt.  The private holdout was frozen before this development package can be
settled.  It is disjoint in domain, actors, objects, syntax, figure order, and
phrases; it cannot be executed until the P1 same-fixture A/B holdout passes.

This package can verify or render only.  It cannot contact a provider.
