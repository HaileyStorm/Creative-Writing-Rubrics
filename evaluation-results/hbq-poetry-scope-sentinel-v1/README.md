# HBQ-RS poetry scope sentinel v1

This public, synthetic, provider-free freeze stages the first 60 calls of the
already frozen 420-call S1 poetry-scope portfolio. It does not add to that
budget. Five current poetry leaves receive four local states—`YES`, `NO`,
`CANNOT_ASSESS`, and `NOT_APPLICABLE`—one leaf per production-rendered request
and three repeated carriers. Labels, oracle rationales, fixture IDs, and slot
metadata remain local to the ledger and never enter a provider-facing prompt.

The screen is diagnostic only. It preserves current wording, IDs, ownership,
polarity, weights, and influence. A later, separately frozen successor may
test one affected leaf only after the sealed holdout gate in the contract.

Run `python run.py --dry-run` to verify the freeze, or `python run.py
--render-plan` to render all singleton prompts without sending them anywhere.
