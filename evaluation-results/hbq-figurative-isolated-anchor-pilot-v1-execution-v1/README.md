# Figurative isolated-anchor pilot executor v1

This development-only executor replaces the contaminated factorial fixture
shape with six independent public synthetic anchors. It changes no rubric
wording, stable ID, ownership, weight, split, QPC24 gate, or Gray Blood state.

Stage 1 evaluates two stockness anchors and two proportion anchors three times
each with the current production prompt. All 12 controls must be correct before
Stage 2 can contact the provider. Stage 2 evaluates one cooperative and one
accidentally conflicting metaphor anchor three times each with one frozen,
leaf-scoped manual checklist. The target treatment explicitly excludes
familiarity/defaultness and sheer figurative load.

The pilot can show only that the manual checklist handles six clean target
anchor calls after clean controls. It is not a baseline comparison and cannot
promote the checklist. A valid target result below 6/6 after 12/12 controls is
the exact development-only DSPy trigger; transport, schema, quotation, or
control failures are not.
