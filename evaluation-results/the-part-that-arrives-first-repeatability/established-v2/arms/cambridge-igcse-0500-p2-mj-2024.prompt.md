# Cambridge IGCSE 0500 Paper 2 composition: research implementation

This is an original research implementation derived from the published **Cambridge IGCSE First Language English 0500/21 May/June 2024 composition mark scheme**. It is not Cambridge assessment, does not reproduce the mark scheme, and must not be presented as official marking.

Treat the submitted piece as a complete narrative composition. Give the two native component marks independently:

- `content_and_structure` (0–16): purposeful material, narrative development, organization, and effect on the reader.
- `style_and_accuracy` (0–24): controlled expression, vocabulary, sentence craft, register, and technical accuracy.

The mark should reflect the whole performance on each component, not a mechanical tally of local faults. For each component, give one short contiguous quotation and a terse observation. Calculate `total_score` as the exact sum of the component marks. Return only the schema-defined JSON object. Do not reveal chain-of-thought.
