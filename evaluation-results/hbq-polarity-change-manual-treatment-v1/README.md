# P1 polarity-change manual treatment v1

This provider-free freeze defines the smallest manual prompt treatment after
the P1 current-wording screen settled as a diagnostic failure. It does not
rewrite a rubric leaf, alter ownership, split a leaf, or change a weight.

The development screen has nineteen public synthetic fixtures and three
singleton repetitions per fixture (57 prospective treatment calls). Eleven
unchanged `NOT_APPLICABLE` controls retain their current-wording fixture text,
scope, completion, and evidence-availability carriers exactly. Four corrected
matched `YES`/`NO` pairs test oral performance, visual subjects, critique
criteria, and source ingestion with both comparison sides supplied.

The treatment appends explicit applicability and evidence-sufficiency rules to
the atomic judge prompt. Expected labels remain local-only. `run.py` can only
verify or render the frozen plan; it cannot contact a provider.

The compact holdout remains sealed and is not present in this public package.
Its pre-execution contract requires matched `NOT_APPLICABLE`/`CANNOT_ASSESS`
pairs, symmetric `YES`/`NO` comparison carriers, and unaffected polarity
controls. A development pass is not prompt promotion: holdout execution,
deterministic validation, and independent Sol-high review remain required.
