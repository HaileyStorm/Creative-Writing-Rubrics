# S1 clean N/A successor executor v1

This development-only successor isolates the single disputed control from the
settled free-verse repetition wording screen. It freezes one complete synthetic
poem with no salient recurring word, phrase, or structure and schedules the
unchanged candidate wording exactly three times as singleton Sol/high calls.

The fixture text and repeat mapping remain in the external private controller.
The public contract discloses the expected state and contains an opaque
three-slot schedule. A verified 3/3 `NOT_APPLICABLE` result authorizes only a
fresh disjoint holdout. It does not promote or alter a leaf, owner, weight,
prompt, rubric, or aggregate.

The predecessor packet remains immutable historical evidence. Its disputed
control is not reused as a future oracle, but its three defensible `NO` verdicts
are not rewritten or relabeled.

Run `python run.py --dry-run --private-root <PRIVATE_ROOT>` to prepare and verify
the exact prompts without contacting a provider. Live execution additionally
requires both explicit command-line acknowledgements and remains one-shot with
no retry or resume.
