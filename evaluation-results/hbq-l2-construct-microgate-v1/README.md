# L2 construct microgate v1

This frozen, public-synthetic diagnostic isolates four construct boundaries
that were not settled by the broader L2 lexical-overlap screen. It is not a
treatment, a replacement for L2, or evidence for a rubric change. The earlier
L2 fixtures and settlement remain historical evidence.

The microgate has four artifacts, two exact owning leaves per artifact, and
three independent singleton repetitions: 24 planned calls and eight cells.
Expected states live only in `expected-ledger.json`; provider-facing prompts
receive neither case identifiers nor ledger fields. Two poetry artifacts bind
the existing free-verse and poem-scope form leaves. Two visual artifacts bind
the existing environment-illustration and visual-craft perspective leaves.

One visual artifact has deterministic generated PNG bytes for an architectural
room/stairwell diagram: four treaded flights carry visible UP markings and
landing labels 0→1→2→3→0, creating a closed always-ascending loop. A
foreground bridge visibly occludes a behind stair at the center. The other
deliberately requires image input but attaches none, so it tests an actual
missing-input boundary rather than a prose substitute. No visual image is
described in text.

The package has no execution surface. A separately reviewed execution
successor may be considered only after independent GPT-5.6 Sol/high review.
Its terminal lifecycle must preserve one terminal receipt per planned slot;
this freeze authorizes no remote contact and no paid route.

Decision rule: all 24 slots and all eight cells at 3/3 closes the issue as
fixture-driven. Any 2/3 cell is variance and a no-go. A 0/3 cell may justify
designing a leaf-specific treatment, but never directly promotes a prompt,
rubric, ownership, split, merge, or weight change.

Run `python run.py --dry-run` or `python run.py --render-plan`. Neither mode
contacts a provider.
