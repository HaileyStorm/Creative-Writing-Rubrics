# CWR-guided revision gain v3 heldout confirmation v1

This provider-free freeze reserves the four V1 held-back HANNA inputs for one
Grok 4.6 revision cycle.  Each source has matched `cwr_guided` and
`generic_no_feedback` descendants; the only allowed arm difference is frozen
CWR feedback.  Four immutable baselines and eight descendants become twelve
blinded targets, each judged independently by Sol and Grok with holistic and
compact instruments (48 endpoint cells).

The package contains fingerprints and schedules, never source prose,
descendants, provider responses, credentials, or queue state.  `study.py`
freezes and validates the contract, payload shapes, opaque target identifiers,
and receipt-only endpoint projection.  `executor.py` deliberately has no
native dispatch path: execution remains **NO-GO** until a separately reviewed
disclosure, route, prepared-record, and native-receipt executor is added.

This can support only a four-item, one-cycle, endpoint-separated heldout
confirmation.  It does not establish human alignment, general literary
improvement, pooled endpoint superiority, provider interchangeability, or a
runtime CWR promotion.
