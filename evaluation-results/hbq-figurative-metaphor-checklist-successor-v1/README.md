# Figurative metaphor checklist successor v1

This is a provider-free, development-only two-phase freeze. It makes no rubric,
leaf, ownership, split, weight, QPC24, or Gray Blood change.

Phase A freezes eight new public, synthetic semantic-construction cases. They
replace the predecessor's ambiguous target-oracle cases without modifying that
predecessor. Every target pair names the same settled subject. The low/high
proportion contrast changes actual figurative load (three versus seven figures),
with the high-load additions assigned to other subjects so they cannot change
target compatibility. The current production prompt is run conceptually as 8 fixtures × 3
leaves × 3 repeats (72 singleton slots). `no_default_metaphors` remains the
stockness owner; `purple_prose.proportion` remains the figurative-load owner.
Phase A stops with `FIXTURE_OR_OWNERSHIP_INVALID` unless each control is 24/24.
With intact controls, it stops `CURRENT_TARGET_SUFFICIENT_NO_CHANGE` only when
the target is 24/24. A mixed 1/3 or 2/3 target cell stops
`CURRENT_TARGET_UNSTABLE_NO_CHANGE`; fewer than two otherwise qualifying stable
misses stop `STABLE_MISS_EVIDENCE_INSUFFICIENT_NO_CHANGE`.

Only a `PHASE_B_ELIGIBLE` Phase A opens Phase B: the target alone across the
same eight cases and three repeats (24 slots), with the exact checklist frozen
in `study-contract.json`. Passing requires 24/24, at least two repaired stable
misses across two stockness/load strata. No treated controls run, so this
package makes no control-regression claim. Passing can make a separate
real-holdout execution successor eligible; it promotes nothing itself.

`real-holdout-commitment.json` freezes eight opaque real-excerpt slots without
authoring or sourcing an excerpt. It expressly excludes Gray Blood. Provider
submission is prohibited before Phase B passes and a separate private carrier
freeze binds eight disjoint excerpt hashes. The eventual executor is also
frozen to zero-incremental-charge-only, no paid fallback,
`terminal_sidecar_v1`, and one physical attempt per planned slot: it may not
retry or resume. This package can only validate or render prompts; it cannot
contact a provider.
