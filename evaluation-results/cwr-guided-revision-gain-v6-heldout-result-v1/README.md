# Heldout CWR revision result

`result.json` is the complete public result schema. It records an aggregate-only four-item heldout comparison: CWR-guided and generic revisions, independently judged by Sol and Grok on holistic and compact measures. Endpoint results are not pooled.

The recorded evidence counts are 4 Sol feedback receipts, 8 exact-one Grok revision receipts, and 48 endpoint receipts. Sol native contact cardinality is unproven; Grok endpoint evidence records one native contact per cell. The package excludes stories, prompts, feedback text, raw adapter output, absolute paths, and personal data.
