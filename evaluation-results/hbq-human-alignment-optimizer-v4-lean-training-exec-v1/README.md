# Lean HANNA training collection adapter

This adapter exposes only the frozen 25 Grok and 10 sprinkled-Sol training rows from the lean development schedule. `--prepare-only` is provider-free and records the inherited local-first disclosure, zero-charge route proof, acknowledgement binding, and exact parent prompt/schema bytes. `--execute-one --allow-remote` dispatches exactly one prepared training cell; it never opens Grok-development or confirmation work.

Preparation is training-row-local rather than delegated to the dev-only executor: it reuses the frozen native payload builder and the audited Grok/Sol route checks while binding the lean row itself. Grok collection emits a native-envelope receipt; Sol collection emits a local-lifecycle receipt and never claims native endpoint contact cardinality. The paired training receipt verifier is required before either form can be included in an optimizer reference manifest.

Example provider-free preparation:

```powershell
python evaluation-results/hbq-human-alignment-optimizer-v4-lean-training-exec-v1/executor.py --prepare-only --output-root C:\safe\lean-training-roots --cell-id <frozen-training-cell> --queue-root C:\Users\Haile\.codex\state\model-work-queue --frozen-successor C:\Users\Haile\Documents\cwr-hanna-successor-fresh88-freeze-v4\frozen-successor-contract.json --hanna-csv C:\Users\Haile\Documents\cwr-hanna-pinned-data-282f275\hanna_stories_annotations.csv --authorization-acknowledgement-sha256 <authorized-sha256>
```

Execution requires an independently reviewed prepared root and `--allow-remote`; there is no batch, development, or confirmation command surface:

```powershell
python evaluation-results/hbq-human-alignment-optimizer-v4-lean-training-exec-v1/executor.py --execute-one --allow-remote --output-root C:\safe\lean-training-roots --cell-id <the-same-frozen-training-cell> --queue-root C:\Users\Haile\.codex\state\model-work-queue --frozen-successor C:\Users\Haile\Documents\cwr-hanna-successor-fresh88-freeze-v4\frozen-successor-contract.json --hanna-csv C:\Users\Haile\Documents\cwr-hanna-pinned-data-282f275\hanna_stories_annotations.csv --authorization-acknowledgement-sha256 <authorized-sha256>
```
