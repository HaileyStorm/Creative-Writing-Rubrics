# Broader Grok development execution v1

This package is the executable descendant of the immutable broader-development
freeze at commit `436da1ef3f8cf239203ac6a80afe8f72708c0415`.  It prepares and
can execute exactly 35 tool-free Grok/high development cells (five fixed
candidates by seven frozen development groups).  Preparation is local-only;
execution requires an explicit current zero-charge route and acknowledgement.

Every cell is one-shot.  A process launch, malformed return, duplicate claim,
or expired lease is terminal/reconcile-required and is never retried in place.
The collector preserves receipt bytes for a later independent equal-group
projection.  It opens no confirmation, selection, promotion, Sol, general,
or runtime authority surface.
