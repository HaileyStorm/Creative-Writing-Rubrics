# HANNA confirmation freeze

This is the compact, provider-free bridge from the broader development result to an untouched confirmation set: the immutable baseline versus Grok-selected `broader-nextwave-13-missing_evidence_not_no` on all 19 confirmation items in eight prompt groups (38 endpoint-neutral logical cells).

The freeze accepts only exact committed result blobs: the pinned Grok development selection and a separately committed Sol validation result whose baseline-to-descendant MAE delta is negative. It then reconstructs sources and human targets from the frozen split, binds the exact outbound payload bytes, and writes a fresh immutable root. It makes no provider calls and has no DSPy/Optuna runtime path.

Run `python study.py --help` for the provider-free materialization interface. A confirmation executor must add its own disclosed endpoint route and preserve these logical cell identifiers and payload bytes unchanged.
