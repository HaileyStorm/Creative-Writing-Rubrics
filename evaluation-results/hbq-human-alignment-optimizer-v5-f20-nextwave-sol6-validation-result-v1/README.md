# Six-cell Sol HANNA validation result

This package replays six immutable, local Codex lifecycle receipts: the original baseline and `normalized-nextwave-08-conservative-hybrid`, each over the same three frozen development prompt groups. The independent replay reports equal-group Sol MAE of **1.2528** for the baseline and **1.1352** for nextwave-08: an absolute change of **-0.1176** and a relative reduction of **9.39%**.

The result is descriptive Sol validation only. It does not pool Sol with Grok, select a prompt, establish generalization, open confirmation, promote a profile, or alter runtime behavior. The lifecycle receipts prove six local Codex process launches; native endpoint-contact cardinality remains unproven. The separately published Grok result is pinned only as source-schedule context, not combined evidence.

`verify.py` checks the public package without provider contact. With all explicit replay inputs it reopens the completed V4 root, recomputes targets and equal-group MAE, and rejects source, payload, route, event, settings, intent, receipt, identity, or reported-record drift.
