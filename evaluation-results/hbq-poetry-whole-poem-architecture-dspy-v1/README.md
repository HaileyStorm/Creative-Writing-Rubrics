# Whole-poem architecture DSPy development freeze

This is a provider-free development package for an instruction-only DSPy
candidate concerning whole-poem architecture. It freezes public-synthetic
TRAIN and DEV cases, a bounded compile design, a static instruction export,
and a separately gated production-transfer plan.

It is neither a runtime dependency nor a rubric change. No model compilation
or evaluation has happened. A passing future transfer can only create a
candidate for manual review; it cannot promote wording, ownership, weights,
or a release by itself.
