# Fresh88 overlap and aggregation views

This offline analysis reconstructs the sealed 88-story Fresh88 verdicts and
already-published HANNA ratings, then publishes several explicitly noncanonical
descriptive views. It keeps the six-dimension mapping, a deduplicated 27-leaf
view, and the intentionally occurrence-weighted 28-occurrence view separate
because `investment` belongs to both Empathy and Engagement.

No verdict is changed, dropped, imputed, or promoted, and no canonical HBQ
weight changes. The 28-occurrence view intentionally counts the shared
`investment` leaf once in each mapped dimension. The output contains hashes, aggregate diagnostics,
and stable public rubric IDs only; private prose, prompts, provider identifiers
or responses, and local paths are excluded.
