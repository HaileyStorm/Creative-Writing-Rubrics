# Balanced DSPy Grok v3 terminal reconciliation

This local-only reconciler reads immutable terminal v3 roots and makes no provider, queue, or subprocess call. It proves the CRLF transport control as strict JSON, then proves request and output commitments in the adapter's compact no-final-LF JSON domain.

The returned instruction and profile bytes remain source evidence. A separate canonical descendant replaces only the profile `instruction_sha256` and serializes that profile in the project JSON domain with one final LF. It never relabels the terminal v3 result as success.

The observed wave contains nine recoverable controls and one zero-byte terminal root (sample 06). `reconcile_partial` therefore emits a nine-descendant partial manifest and records the required fresh v4 replacement; it cannot write a ten-descendant aggregate or resend the terminal root.
