# CWR-guided revision gain v2 lean pilot

This is a provider-free execution contract for the smallest useful CWR-guided revision comparison. It freezes two existing HANNA sources (`hanna-1035`, `hanna-178`), one Grok generator, two cycles, and matched `cwr_guided` / `generic_no_feedback` descendants. The resulting eight immutable descendants, together with the two immutable baselines, are assessed through forty blinded endpoint cells: two judges (Sol and Grok) crossed with two non-CWR instruments.

The contract creates no provider contact. `freeze_inputs` fingerprints and checks the two external source/prompt pairs without copying prose, invokes the current pinned CWR runner, and freezes its exact question payload in the authorized work root. `prepare_cell` writes an exclusive exact outbound payload plus schema commitment for one scheduled CWR-feedback, revision, or endpoint cell. Source and target prose may exist only in that authorized local root; nothing is committed by this package. Endpoint preparation accepts only a locally frozen target manifest, never a caller-supplied target mapping. It requires an exact zero-charge acknowledgement hash before it produces a provider-ready preparation, but it cannot dispatch. A prepared root refuses a second preparation. `begin_one_launch` and `record_terminal_outcome` provide the provider-free one-launch/reconcile boundary: a precontact failure requires a fresh root; any postlaunch outcome is terminal and requires reconciliation rather than resend.

Every live result must later bind its immutable prepared record and frozen manifest, native provider/model/reasoning/session/request identity, tools-disabled declaration, and returned response bytes before `validate_receipt` writes an immutable verified receipt. Guided revision lineage requires both that verified Sol feedback receipt and its verified Grok revision receipt; cycle two can only use its declared cycle-one descendant. `prepare_targets` constructs the ten immutable blinded targets. `project_independent_metrics` accepts only the complete persisted verified endpoint receipts and independently recomputes guided-minus-control plus both arms versus the source baseline, separately for each judge and scale. It has no selection, promotion, or runtime path.

This is a small development pilot, not a claim of human alignment, general literary quality, or provider interchangeability. The public package contains no source prose, generated descendants, provider responses, credentials, or queue state.
