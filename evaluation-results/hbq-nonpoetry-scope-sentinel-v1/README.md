# HBQ-RS non-poetry scope sentinel v1

This public, synthetic, provider-free freeze stages the first 60 calls of the
already frozen 300-call S2 non-poetry scope portfolio.  It does not add to that
budget.  Five current leaves each receive the same four scope states, one leaf
per production-rendered request and three repeats: a localized issue that is a
revision note, a material failure at the declared scope, missing required
evidence, and an activation mismatch.  The resulting labels are respectively
`YES`, `NO`, `CANNOT_ASSESS`, and `NOT_APPLICABLE`; those labels live only in
the local slot ledger and are never passed to the renderer.

The study binds current leaf records, criterion ownership, the production judge
prefix, binary prompt, response schema, and renderer.  It uses synthetic
evaluation, procedure, critique, passage, and creative-text artifacts so a
procedure or scope leaf is not exercised through an unrelated prose surrogate.
It is a frozen development screen: no provider mode, no result, and no prompt,
rubric, leaf, ownership, split, or weight promotion.

Run `python run.py --dry-run` to verify the freeze, or `python run.py
--render-plan` to render all provider-facing singleton prompts without sending
them anywhere.
