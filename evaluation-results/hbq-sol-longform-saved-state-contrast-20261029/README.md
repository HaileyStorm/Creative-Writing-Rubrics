# Long-form saved four-state agreement

A provider-free analysis compared two saved HBQ passes on one retained novella.
The 139 matched leaf judgments agree on 132 states: **94.96% raw agreement** and
**Cohen's kappa 0.8272**. Both views use the existing
p4_crlf_span_grounding_v1 quotation policy. The earlier pass is cycle0; the
later view is cycle2's selected tail.

This is an availability-selected descriptive comparison. Historical native
runtime and transport differ, and equivalence of the older tool-disable controls
and effective sampling is unestablished. It is not a controlled identical-runtime
repeatability estimate, human-alignment result or validation of literary quality.

One earlier packet was rejected; a different later packet has no qualified
projection because it violates its retained schema and contains malformed summary
evidence. Original responses and rejections remain unchanged. The separate later
grounded view admits 19 of20 packets and147 of155 leaves; the paired comparison
also requires an admitted earlier counterpart.

The seven state changes are three YES to NOT_APPLICABLE, one NO to YES, one
NOT_APPLICABLE to NO and two NOT_APPLICABLE to CANNOT_ASSESS. The full16-cell
transition table and both marginal distributions are in report.json.
CANNOT_ASSESS and NOT_APPLICABLE remain distinct. Leaves share packets and a
single work; they are not139 independent population observations.

For all155 selected leaves, assigning every unresolved pair disagreement gives
132/155 = **85.16%** agreement; assigning every unresolved pair agreement gives
148/155 = **95.48%**. These are missing-outcome bounds, not a confidence interval.
They do not describe all219 leaves or the current221-leaf bank. Raw agreement
and kappa depend on state prevalence: the earlier matched set has117 YES,8 NO,
1 CANNOT_ASSESS and13 NOT_APPLICABLE; the later set has115,8,3 and13 respectively.

Matching required identical frozen source/context, ordered question IDs,
compiled bank, prompt/rendering and schema commitments. The calculation reused
existing saved qualification and the existing agreement arithmetic; it did not
replay native returns, requalify or score a whole bank. No model calls, new votes,
story/prompt reads, human-label reads, recruitment or calibration occurred.

The public files contain aggregate counts and opaque source commitments.
Reproduction requires the retained private qualified ledgers and projections.
The algorithm counts identical four-state pairs, computes Cohen's kappa from
their marginal expected agreement, and reports all planned155 leaves separately.
No missing observation is replaced or treated as a vote.

No candidate, baseline or release is promoted. The broader research and release
program remains incomplete.
