# Lean HANNA training receipt verifier

This provider-free successor admits the frozen training geometry only after it has independently replayed all 35 immutable collector roots: 25 Grok primary rows and 10 sprinkled Sol rows. It binds the verifier contract/source, collector, lean optimizer, native scheduler, and pinned exec-v1/v3 paths by exact SHA-256; rederives every frozen row, all seven prepared artifacts, outbound payload, prompt, schema, provider/model identity, raw response, record, effective settings, result, receipt, and human target. It produces per-cell observations only after the complete ordered set verifies. It does not accept aggregates, raw caller scores, development rows, confirmation rows, partial collections, empty records, or a substitute Sol identity.

Grok observations retain the native envelope path. Sol observations retain the exact ceiling `local_codex_lifecycle_received_native_contact_unproven`; a received local lifecycle is not relabeled as native endpoint-contact cardinality.

The projection is development-only optimizer input. It has no runtime, candidate-selection, confirmation, or provider-dispatch authority.
