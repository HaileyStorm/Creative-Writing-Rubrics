# Figurative Phase A aggregate-only public result v1

This is the aggregate-only public projection of the settled
`hbq-figurative-metaphor-checklist-successor-v1-execution-v1` Phase A
execution. It does not copy the external execution root, fixtures, prompts,
expected outcomes, responses, evidence, or per-call results.

All 72 planned singleton text calls were accepted on their first attempt. The
settled outcome is `FIXTURE_OR_OWNERSHIP_INVALID_NO_GO`: this study cannot
support a target-wording claim because its shared synthetic fixture design did
not cleanly isolate the three intended concerns.

The independent review identified three practical fixture problems. Some
stockness-positive carriers also used familiar default imagery, so they could
not test the stockness control independently. Some nominally low-load carriers
contained enough figurative material to be a reasonable proportion failure.
And some target carriers introduced competing imagery or otherwise mixed the
target concern with another leaf's concern. Those observations invalidate the
shared oracle/fixture panel; they do not establish that any target wording is
wrong.

Phase B was disabled, the real-text holdout was not opened, and no promotion
occurred. `no_default_metaphors` remains the owner of stockness; figurative
density remains in `penalty.purple_prose.proportion`. The next repair is a
smaller, independently controlled fixture panel before any later wording
treatment is considered. DSPy was not used in this execution; it remains a
development-only fallback if a clean manual repair later proves inadequate.

`public-result.json` contains only aggregate counts and commitments to the
settled records, without paths or private content.
