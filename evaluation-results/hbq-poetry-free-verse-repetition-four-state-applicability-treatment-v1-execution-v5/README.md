# S1 four-state applicability treatment executor v5

V5 preserves the v4 exact-quote protocol and its honest v2 lineage, but
replaces the absence control. The earlier absence prose repeated a common word,
so a NO could be defensible. V5’s absence artifact is one sentence and one
line; a deterministic check rejects any repeated case-folded lexical token or
contiguous two-token phrase before a freeze can proceed.

The candidate wording, four-state 12-call geometry, Sol/high singleton route,
no-retry policy, quote-only evidence schema, and zero-normalization gate are
unchanged. A successful screen authorizes only a fresh disjoint holdout; no
result promotes a leaf or changes ownership, weight, influence, prompt, or
rubric.
