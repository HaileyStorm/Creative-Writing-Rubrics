# Saved transport recovery v1

This private, provider-free reconciliation preserves native failures and adds
named descendants under `saved_transport_recovery_v1`. It does not reconstruct
an original Grok envelope, prove physical contact counts, or create extra votes.
Frozen runners, native readers, study collectors and original terminals remain
unchanged. Planned repeats retain their original identities.

`reconcile.py` covers the complete reserved P1 matched-002 and MFA original plus
context-v2 prefix chains. A metadata-only config supplies `study` (`p1` or `mfa`),
`manifest_path_local_only`, `manifest_sha256`, `tools_root_local_only`,
`secondary_home_local_only`, `grok_sessions_root_local_only`, and exactly two
`sources` with `endpoint`, `root_local_only`, and `job_sha256`. MFA additionally
requires `context_reconciliation` with `path_local_only` and `sha256`. Use exact
retained job hashes, including every terminal failed slot. No source outcome
selects the untouched suffix. Full denominators remain 1,584 P1 and 868 MFA.

```powershell
python -B reconcile.py --config <private-config.json> --config-sha256 <raw-sha256> --output-root <fresh-private-directory> --dry-run
```

Omit `--dry-run` only for the owning root's actual write. The fresh directory
contains a private reconciliation ledger and immutable raw native snapshots.
Verification replays these snapshots without requiring account history. Public
stdout contains counts and hashes only. Source locators, UUIDs and creative
responses remain private. The native `recover_sol` callable also validates the
demonstrated completed TTCW Sol slot 391; incomplete or unknown failures remain
unadmitted. TTCW whole-chain continuation and its 3,108 denominator are owned by
the separately versioned TTCW preparation/analysis path.

Sol recovery drops only the observed DNS reconnect/HTTPS fallback diagnostics
from a separately hashed events projection, then calls the unchanged own-turn
reader on the original rollout and final. Grok recovery validates exact selected
session, prompt, model/effort, update times and content, permits only the observed
HTTP decode/DNS `retry_state` records, and invokes the unchanged TTCW saved-history
reader on the projected update sequence. Raw diagnostics remain in snapshots.
Unknown errors, tools, foreign identities, multiple or incomplete turns cannot
be admitted. Completed schema or grounding failures remain missing evidence.

`collector.py --reconciliation <receipt> --reconciliation-sha256 <sha> --endpoint
<sol|grok> --results-dir <fresh-private-sibling> --validate-only` verifies the
untouched suffix without account probes or contacts. Grok additionally requires
`--route-root` and exact `--route-sha256`. Actual collection uses the designated
secondary native Sol account or reviewed Grok route, one worker, 900 seconds and
one logical attempt with zero retries. STOP prevents the next contact while the
current bounded call settles; Grok requires a 900-second margin before
2026-10-16T05:40:00Z.

A completed demonstrated transport failure may be reconciled locally in its
new owned slot, retaining the original terminal plus separate native snapshots,
`transport-reconciliation.json` and `effective-terminal.json`. A fully completed
schema/grounding rejection remains missing and permits the next untouched slot.
Unknown or incomplete native failures stop. Every started slot occupies its
identity; interrupted local recovery never authorizes resending.

`analysis.py --reconciliation <receipt> --reconciliation-sha256 <sha> --sol-suffix
<directory> --grok-suffix <directory>` joins each original logical vote once and
uses existing context-aware strict full-bank scoring. Missing/incomplete banks
have no scalar. P1 remains descriptive synthetic evidence without accepted
oracles. MFA remains a two-target development canary without powered or fresh
confirmation claims. MFA human labels require the explicit
`--release-development-labels-postprediction --sealed-source-root <root>` option
after all 868 planned slots are terminal; the original exact `Excerpt1`/`Excerpt2`
ordered decoder remains unchanged.
