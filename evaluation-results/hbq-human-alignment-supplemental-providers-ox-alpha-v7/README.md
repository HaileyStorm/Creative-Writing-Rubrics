# Ox Alpha v7 transport successor

This outcome-blind, score-blind probe inherits the three public HANNA cells and
the first four leaves from immutable v6. GPT-5.6 remains the primary condition.

V6 is immutable uncertain evidence, not a pass: it completed one cap-1,
request-v2 HTTP 200 in 111.5274232 seconds, with four schema-valid verdicts,
run/verdict/diagnostic, accepted-message, request/result, checkpoint, and raw
evidence. It made no journal or semantic receipt. Its first observed failure was a v6
selector that treated `batch-0001.attempt-0001.nous.request.json` and
`batch-0001.attempt-0001.nous.result.json` as checkpoints. V7 retains every
v6 immutability, disjoint-root, proof, privacy, cap-1, and no-retry gate, while
selecting checkpoints only with `batch-[0-9]{4}.json` and rebuilding expected
prompt assets and source/context text with byte-preserving UTF-8 decoding. The latter corrects a
second deterministic latent verifier defect: text-mode reads normalized CRLF.

Each v7 cell is one serial four-leaf cap-1 request. The launcher wait remains
240 seconds and an accepted raw HTTP attempt must remain below 150 seconds.
The package retains raw HBQ verdicts, rationales, and diagnostics as transport
evidence only: it produces no human labels, composite scores, correlations,
rankings, or alignment analysis. It authorizes neither paid evaluation, DSPy,
nor new human judging.

Prepare only after fresh zero-cost proof is available:

```powershell
python prepare_transport_successor.py --uncertain-v6-work-dir <immutable-v6-root> --zero-cost-proof <fresh-proof.json> --work-dir <empty-external-root>
```

The separate launch command requires review of the frozen root and current
shared cap-1 runtime.
