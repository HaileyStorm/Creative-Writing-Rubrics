# Figurative hinge treatment successor v1

This small development-only pilot follows the consumed r9 DSPy search result.
It tests one narrower manual distinction: a connective alone does not make
opposing figurative implications cooperate; the supplied artifact needs an
additional concrete semantic hinge.

There are two construct-pure positive controls and two construct-pure negative
controls, each repeated twice: eight singleton GPT-5.6 Sol/high contacts if a
later independent Sol review authorizes execution. The corpus is public
synthetic; expected labels remain only in the private ledger. This has no
TRAIN/DEV split, runtime DSPy dependency, rubric change, split, or promotion.

Provider-free freeze:

```powershell
python run.py --dry-run --private-root <fresh-private-root>
```

The future command is deliberately not executable from this package until a
separate review supplies an execution adapter and approval. It must preserve
one attempt, zero retries or normalization, source-exact quotation, and the
same eight-call geometry.
