# HBQ polarity mechanism corpus

This pre-execution package is an executable public synthetic mechanism check. Its frozen input artifact contains short, reviewed positive and clean-negated criterion probes, never story prose, prompts, provider output, runtime receipts, or local paths.

It is not semantic-validity evidence. Positive HBQ wording and the production scorer remain canonical. Any empirical work belongs in a separately frozen successor that binds a distinct approved corpus, real batch artifacts and results, exact complete-stack provenance, and disjoint development and held-out cells; it cannot rewrite this package.

`polarity_harness.py` is stdlib-only and offline. It validates the independently pinned contract projection, corpus bytes and hashes, review provenance, authoritative criterion ownership, four-state decoding, and the publication allowlist.
