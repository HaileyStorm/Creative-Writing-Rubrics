# Exact-duplicate repeatability aggregate result

The supplied source report describes three independent current-contract
judgments of each of two byte-identical artifacts. This aggregate-only package
publishes a reproduced arithmetic projection of those source-reported runs:
observed scores, bounds, coverage, statuses, opaque run hashes, and
deterministic derived summaries. It does not establish verified
FreshReplicateReceipt evidence. It contains no artifact or context text,
prompts, raw responses, request or session identifiers, or private locations.

The result is `EXPLORATORY_DIRECTIONAL_ADVANTAGE_NO_PROMOTION`. The
creative-reasoning artifact has a higher median and a higher
median-minus-MAD summary than the Off artifact, and wins eight of nine
descriptive cross-replicate comparisons. That directional observation does
not promote a default, change the rubric, or substitute for a paired or
larger replicated decision.

The Off duplicate-control range is material. In particular, the two groups'
ranges overlap: the creative-reasoning minimum is below the Off maximum.
`batch_attempts` are not represented as statistical replication; the supplied
source report describes each listed row as a separate replicate and supplies
an opaque run hash. Those hashes have not been independently verified on this
host; they are not the reusable per-run receipt contract requested for future
work.

Two reported stack bindings are deliberately omitted as unverified: the
reported compiled-bundle hash and the reported full-stack hash field. The public
package makes no claim for either binding, and includes no replacement
compiled-bundle hash because a canonical recomputation available while this
package was prepared did not confirm the requested successor value. This
restriction keeps the aggregate useful without presenting an inconsistent
stack claim as settled evidence.

differences (MAPD), directional gaps, and the 8/9 descriptive superiority
