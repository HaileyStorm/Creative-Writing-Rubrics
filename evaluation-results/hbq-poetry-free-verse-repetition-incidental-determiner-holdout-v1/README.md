# S1 incidental-determiner holdout

This small synthetic holdout checks the approved recurrence treatment against a
plain incidental determiner recurrence.  It uses three fresh opaque singleton
slots, freezes the renderer's raw UTF-8 prompt bytes, and is unexecuted at
creation.  The expected state and slot mapping remain in the private execution
bundle.  It is a development check only: no promotion follows from this package
alone.
