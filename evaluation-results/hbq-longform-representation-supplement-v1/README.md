# Long-form representation access: retained descriptive comparisons

The retained two-novella pilot includes matched comparisons of raw full text,
anchored maps and summaries. In the observed HBQ pairs, raw-context YES/NO answers
became CANNOT_ASSESS with either restricted representation. This measures access
and abstention sensitivity; it does not establish which answer was correct.

This supplement copies six existing Sol comparison summaries into
[`aggregate.json`](aggregate.json). It performs no new scoring or scientific
replay. It supplements the separate
[retained cross-form synthesis](../hbq-retained-crossform-descriptive-v1/README.md)
and the one-novella repeatability experiment; these have different denominators.

The design has six dependent cases from two novellas and three planned cycles.
Each representation contrast therefore plans 18 case-cycle pairs, or 54 HBQ leaf
pairs. Those pairs are not independent works. Cycle 0 covers all six Sol cases in
each representation and both diagnostic arms; cycle 1 is partial and cycle 2 is
untouched. All 108 planned Grok diagnostic positions are not supplied.

HBQ native-state agreement is respectively 0, 0 and 1; saved kappa is 0, 0 and
undefined. Agreement between two abstentions does not establish successful
dependency discrimination. Saved holistic exact agreement is 5/7, 1/4 and 1/4.
Means and differences describe native ordinal rating codes, not calibrated utility.
The JSON preserves the original full-precision values, nulls and missing counts.

Uneven assessed availability, dependent case-cycle observations, model familiarity
and post-prefix exploratory grounding limit interpretation. There is no established
human validity, causal superiority, literary correctness or complete whole-work
HBQ/comparator comparison. Logical inventory positions do not establish physical
provider-contact totals. No confidence interval or candidate promotion follows.
