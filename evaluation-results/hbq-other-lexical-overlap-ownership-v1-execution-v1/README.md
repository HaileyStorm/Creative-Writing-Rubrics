# L2 lexical-overlap execution v1

This is the separately frozen, zero-paid execution successor for the public
synthetic L2 lexical-overlap screen at `5d31848`. It schedules 216 singleton
GPT-5.6 Sol/high calls: six leaves across 36 matched-carrier artifacts and
three repetitions. It permits at most 648 cumulative sends.

The visual block has 72 slots. Each one is delivered with the exact frozen PNG
bytes through `codex exec --image`; a prose description is neither generated
nor accepted as a replacement. The predecessor's fixture-manifest and
generator hashes are checked before preparation, execution, and settlement.

`--dry-run` writes the durable private schedule, canonical rendered prompts,
and immutable input copies without provider contact. `--execute` and
`--resume` require both remote and zero-incremental-charge acknowledgements.
Every remote attempt has a unique deterministic run and attempt identity, its
own intent, receipt, response, and outcome directory. A definitively returned
but invalid structured response is replaced at most twice, preserving the
rejected attempts and counting one accepted logical vote. An interrupted or
ambiguous contact is quarantined for reconciliation instead of being resent.

Settlement validates the strict response schema, singleton question identity,
typed evidence, exact text quotes where a textual artifact exists, attachment
hashes for visual artifacts, prompt and runtime commitments, unique run
identities, and all three repetitions. Results remain private until a separate
aggregate-only result package is reviewed. No prompt, rubric, ownership,
split, or weight change is authorized here.
