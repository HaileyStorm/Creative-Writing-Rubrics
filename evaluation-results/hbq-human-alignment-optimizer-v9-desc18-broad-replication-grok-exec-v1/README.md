# Desc18 open-split Grok execution

This is the ten-lane, no-fallback/no-resend Grok executor for the provider-free Desc18 Fresh96 open-validation replication freeze. It pins the committed Desc17 lifecycle stack and sends each admitted payload unchanged with tools, web search, plans, and subagents disabled.

Before any contact it rejects a missing, pointer-like, or non-full-text writing payload, including filesystem paths, URI schemes, hashes, and cell-like IDs while retaining ordinary prose titles. After a response returns, it admits only the exact `scores`/`evidence`/`coverage` structure: each has exactly the six HANNA dimensions; scores are finite numeric values in 0–5; coverage values are booleans; and evidence is substantive rather than blank or placeholder/workspace-search text. Post-launch failures remain immutable terminal outcomes; neither execution nor collection can silently resend them.

Cost evidence is parsed as timezone-aware timestamps and must be live at preparation and immediately before every provider contact. A wave keeps one collector-consistent route binding, but each lane rechecks that the proof has enough remaining lifetime for its own timeout plus a small margin; an expired or near-expiry lane is terminal and never sent or resent.

This produces open-split development evidence only. Confirmation and reserve remain unopened, and native endpoint contact cardinality remains unproven unless separately evidenced.
