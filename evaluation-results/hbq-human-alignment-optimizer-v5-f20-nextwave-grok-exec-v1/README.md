# HANNA next-wave Grok candidate generation

This package freezes ten distinct, tool-free Grok generation cells from the public `f20f817` descriptive HANNA result. It imports exact baseline and current-best instruction/profile bytes, sends one immutable parent plus one distinct conservative variant brief per cell, and stores only versioned descendants.

`prepare-all` makes no provider contact. `execute-one` and `execute-wave` require an explicit current zero-charge Grok route, write launch intent immediately before the one allowed runner invocation, and never resend a root. `execute-wave` uses at most ten concurrent cells.

Outputs are provisional candidate-generation evidence: Grok reasoning and native endpoint-contact cardinality are not independently attested. This package does not judge, select, promote, open confirmation, provide runtime authority, or establish any HANNA gain.
