# HANNA v4 prompt candidates

This is a public-safe, development-only catalog of prompt descendants. It binds one
tool-free DeepSeek V4 Flash result and one eight-mechanism GPT-5.6 Luna source lane.
The raw Nous request and result are retained byte-for-byte in this package; the
catalog records their hashes and DeepSeek's transport blockers unchanged. Its
`exact_gate_eligible` status is `false`, so the DeepSeek output is provisional
candidate-generation input only.

The 12-entry shortlist is not a winner list. Eight entries retain Luna wording
verbatim. Four others are new local descendants inspired by mechanically distinct
DeepSeek mechanisms; each names its raw parent prompt hash and explicitly says it
was rewritten locally. All entries share the fixed parent candidate, Fresh88 mapping,
equally weighted six dimensions, zero demonstrations, and unchanged Grok/Sol task,
schema, and story bytes when later evaluated.

No catalog entry has runtime, selection, confirmation, provider-dispatch, or
empirical-alignment authority. Later frozen-partition evaluation must independently
bind the exact candidate bytes to native evidence before it can make any result or
selection claim.
