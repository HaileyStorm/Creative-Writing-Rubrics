# V12 matched development panel

This package evaluates the unchanged baseline and retained child20 profile on
the frozen seven-group, thirteen-item development partition: 26 Grok cells.
It is development measurement only. It opens no confirmation cells, does not
dispatch Sol, and makes no selection, promotion, runtime, DSPy, or Optuna
claim. Earlier results remain unchanged.

Three prior baseline observations are context only: their preserved root is
`cwr-hanna-nextwave-score-6cfd64e-20260831a` and schedule hash is
`e8de7435e7cb1cab43f2a4d99438b2d136f6b763e758766cf3fe8626e1eda9e5`.
They are planned repeats, not adopted cells or extra votes in this panel.

The requested Grok route is `grok-4.6`, whose accepted CLI usage key is
`grok-4.6-build`, with `high` reasoning and tools off. Reasoning is not
provider-attested; execution must preserve that limitation in its receipt.

`study.py` reconstructs the source aliases from the pinned V1 map, generates
the exact V10-format payload bytes, and composes the already-pinned V11 lower
lifecycle. `prepare_all` is provider-free. `execute_wave` requires an explicit
remote route and acknowledgement; it dispatches at most ten cells concurrently
through the shared lower global-slot limit. `report` accepts only complete,
admitted native receipts with one common route/evidence binding and independent
request and session identities.

The primary metric first computes each item's six-dimension absolute error,
averages those errors within each prompt group, then gives all seven groups
equal weight. Rank correlations are secondary context, explicitly labelled as
13-item or 7-group-mean Spearman values. All finite numeric scores are kept
even when a coverage flag is false.

There is no standalone dispatch CLI. The public API is intentionally narrow:
`schedule`, `prepare_all`, `execute_wave`, and `report` each require the pinned
split manifest, HANNA CSV, and frozen successor contract paths. No payload is
reused for Sol automatically; later Sol measurement needs a separate package
and gate.
