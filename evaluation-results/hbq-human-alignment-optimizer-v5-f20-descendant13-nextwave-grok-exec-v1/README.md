# Descendant-13 next-wave Grok candidate generation

This versioned package derives exactly ten conservative, nonduplicate Grok candidate briefs from the published descendant-13 development profile at `1a432fb`. It freezes the literal parent instruction/profile and a canonical six-dimension outbound payload before any contact.

`prepare-all` and `reconcile-all` are provider-free. `execute-one` or `execute-wave` needs an explicit current zero-charge governed Grok route and is one-shot: any post-launch uncertainty requires a fresh output root. The wrapper accepts `--parent-profile` on every CLI mode and refuses parent, route, payload, response, identity, or reparse drift.

These are development-only candidate proposals. They do not select a profile, establish a result, alter runtime behavior, promote anything, or make a general HANNA claim.
