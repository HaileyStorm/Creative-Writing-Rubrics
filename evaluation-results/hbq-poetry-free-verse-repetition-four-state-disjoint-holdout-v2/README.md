# S1 four-state disjoint holdout v2

This is a versioned, provider-free carrier-repair successor. It retains three
public-synthetic carriers from v1 and replaces one catalog-style carrier with
a fresh identifier and fresh tokens. The predecessor's external evidence is
immutable.

The v2 freeze uses twelve shuffled opaque singleton slots and production
rendering with the inherited exact-quote protocol. Its prompt scan rejects
provider-facing study-role labels, outcome-map terms, and case identifiers.
No provider calls occur during validation or dry rendering, and the CLI has no
execution mode.

The externally sealed outcome map is not provider-visible. A future reviewed
execution could open only independent promotion review on twelve exact
first-attempt, source-exact matches; it cannot itself promote a wording,
split, owner, weight, applicability, evidence-policy, or runtime change.
