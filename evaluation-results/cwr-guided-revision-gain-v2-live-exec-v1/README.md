# CWR-guided revision gain v2 live execution v1

This is the governed one-cell adapter for the committed v2 lean pilot. It is pinned to `37ba2cb` and refuses any changed pilot byte. It has no automatic provider dispatch: preparation reads the current model-work-queue registry, delegates route and fresh subscription-evidence validation to the queue's own validator, and persists the resulting exact-route proof. Execution still requires an explicit remote flag and revalidates that live route before its one launch.

The adapter invokes only the tool-free `codex_exec.py` and `grok_exec.py` artifacts selected by that validated registry using their canonical `{\"prompt\": ...}` wrapper. Tools, web access, planning, and subagents remain disabled. Grok maps the prepared `grok-4.6` route to `grok-4.6-build`; a completed one-turn envelope must carry distinct native request and session hashes and is recorded as exactly one native contact. Codex's current envelope records a local requested-model lifecycle and thread projection but no independently attested native endpoint/contact cardinality. Sol feedback and blind-judge outputs therefore remain usable as the explicit `sol_local_codex_lifecycle_native_endpoint_cardinality_unproven_v1` evidence class and are never relabeled native.

Preparation is provider-free. Dispatch creates one launch intent, writes no resend path, and routes validation failures before process creation to precontact terminality; ambiguity after process creation requires reconciliation-only receipt ingestion. Every downstream feedback, revision, target-freeze, and endpoint projection reads exactly one receipt authority: either the original verified receipt or its reconciled successor. Dual authorities and remint attempts fail closed.

The executor independently replays all 40 endpoint authorities before projection. Guided-versus-control and arm-versus-baseline metrics remain separated by judge route and measure: Grok rows retain their native exact-one-contact evidence class, Sol rows retain their local-lifecycle/cardinality-unproven ceiling, and no cross-endpoint pooled statistic is emitted. Revalidation also reopens the frozen target manifest and exact blind payload, preserving unchanged within-route pairs.
