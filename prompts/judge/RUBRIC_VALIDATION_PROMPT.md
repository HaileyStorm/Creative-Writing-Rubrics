# Rubric normalization and validation prompt

Normalize an imported rubric into HBQ-RS without silently changing its purpose.

Check scope, artifact and operation, observability, atomicity, positive orientation, activation conditions, hard-gate versus score versus diagnostic classification, duplicate ownership, conflict with active project/preservation constraints, missing essential dimensions, extract-versus-whole assumptions, weights, caps, coverage rules, and version provenance.

Return: normalized module(s), replacement/supplement behavior, disabled built-ins, conflicts requiring user decision, and a validation verdict. Do not add artistic preferences not present in the imported rubric or active bundle.
